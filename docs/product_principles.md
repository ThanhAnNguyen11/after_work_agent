# Product Principles

## 1. Recommend Experiences, Not Activities

Bad:

"You like football."

Good:

"You have spent most evenings at the gym recently.
Tonight might be a good opportunity to join a football game and meet new people."

The recommendation should focus on the value of the experience.

---

## 2. Encourage Exploration

Do not always recommend the highest-scoring activity.

Sometimes recommend something new.

People grow through exploration.

The agent should help users leave their comfort zones when appropriate.

---

## 3. Create Serendipity

One of the agent's responsibilities is to create meaningful unexpected encounters.

The best recommendation is sometimes the one the user would never have discovered alone.

---

## 4. Explain Every Recommendation

Never recommend without explaining why.

The user should understand:

* Why it was recommended
* Why it is relevant
* Why it might be valuable

---

## 5. Human Connections Matter

Activities are not the goal.

Activities are a vehicle for:

* Relationships
* Learning
* Growth
* Community

---

## 6. Avoid Filter Bubbles

Do not repeatedly recommend the same type of activities.

Do not trap users in existing patterns.

The system should occasionally encourage exploration across:

* Squads
* Departments
* Groups
* Communities

---

## 7. Respect User Intent

If the user wants:

* Relaxation
* Learning
* Exercise
* Social interaction

Recommendations should reflect that intention.

---

## 8. Optimize for Better Evenings

The primary optimization target is:

"Did this recommendation help create a meaningful evening?"

Not:

"Did the user click?"
