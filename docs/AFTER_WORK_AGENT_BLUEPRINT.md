# AFTER WORK AGENT - MVP BLUEPRINT

## 🎯 NORTH STAR

Help employees discover and join after-work activities happening inside the company.

The goal is to make activities easier to discover, easier to join, and help employees connect with more communities.

---

## 📚 BLUEPRINT SECTIONS

This product blueprint is split into modular sections to make it easy to manage and control:

1. **[Core Product & Features](file:///Users/lap15569-local/Documents/work/python_projects/after-work-agent/docs/1_core_product.md)**
   - Authentication, login credentials, first login onboarding profile requirements, interest checklists, activity discovery, dynamic and fixed activity types, and participation tracking.

2. **[Activity Lifecycle](file:///Users/lap15569-local/Documents/work/python_projects/after-work-agent/docs/2_activity_lifecycle.md)**
   - Activity creation, participant capacity controls, prep guidelines, host notifications when someone joins, and full-capacity locking.

3. **[Data Model](file:///Users/lap15569-local/Documents/work/python_projects/after-work-agent/docs/3_data_model.md)**
   - Entities and fields for Users, Activities, Activity Participants mapping, and Participation History.

4. **[Agent Responsibilities](file:///Users/lap15569-local/Documents/work/python_projects/after-work-agent/docs/4_agent_responsibilities.md)**
   - Input/output specifications for the Recommendation Agent, Extraction Agent, and Participation Collection (feedback loop) Agent.

5. **[Agent System Prompt](file:///Users/lap15569-local/Documents/work/python_projects/after-work-agent/docs/5_system_prompts.md)**
   - Identity rules (friendly, helpful, curious), cold start protocols, and grounding guidelines to avoid hallucinated preference history.
